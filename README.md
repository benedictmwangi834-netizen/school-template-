# 🎓 Stratify School Portal

A complete, modern school management system with dashboards for students, teachers, parents, and administrators.

## 📋 Features

### 🏠 Home Page

- Hero section with school branding
- Statistics dashboard
- About, Services, Contact sections
- Login with role-based authentication
- Book Demo button

### 👨‍🎓 Student Portal

- Exam results and grades
- Attendance tracking
- Fee balance
- Timetable
- Assignments

### 👨‍🏫 Teacher Portal

- Upload results (CSV or manual)
- Record attendance
- Share learning materials
- Class management

### 👨‍💼 Admin Portal

- Student management
- Class management
- Fee management
- Reports & analytics

### 👨‍👩‍👧 Parent Portal

- Track children's progress
- View grades and attendance
- Fee payment status
- Notifications

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- JavaScript (ES6)
- Node.js with Express
- Font Awesome for icons
